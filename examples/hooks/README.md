# Hook Examples

These examples are generic public patterns. Adapt them carefully for your own
environment.

Hooks can execute local commands, so review them like code before use.

## Examples

- [pre-tool-guard.example.json](pre-tool-guard.example.json): a placeholder
  configuration for guarding write-like tools.
- [prompt-context.example.json](prompt-context.example.json): a placeholder
  configuration for injecting local context before a prompt is processed.

The command paths in these examples are intentionally placeholders. Replace
them with scripts your team owns and audits.
