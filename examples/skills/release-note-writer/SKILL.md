# Release Note Writer

Use this workflow to turn verified changes into clear public release notes.

## Inputs

- changed behavior;
- affected users;
- compatibility notes;
- install or upgrade impact;
- verification evidence;
- known limitations.

## Output

Write release notes with:

- a short user-facing summary;
- concrete changes;
- migration or upgrade notes when needed;
- known limitations;
- verification summary.

## Style

Use plain language. Avoid hype, unnecessary implementation details, and claims
that are not supported by release evidence.
