# Skill Examples

These are public examples of Reflective-style skills. They are intentionally
generic and should not be treated as company-specific policy.

## Examples

- [incident-aware-debugging](incident-aware-debugging/SKILL.md): guide an agent
  to check incident context before changing code.
- [release-note-writer](release-note-writer/SKILL.md): turn verified changes
  into concise release notes.

## Public Skill Standard

Public skills should:

- describe one workflow;
- state the expected output;
- include safety boundaries;
- avoid private company data;
- avoid unsupported product claims.
