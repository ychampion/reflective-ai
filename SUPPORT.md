# Support

Reflective is coming soon. Public support is currently handled through GitHub
Issues and Discussions in this repository.

## Where To Ask

- Use [Discussions](https://github.com/ychampion/reflective-ai/discussions) for
  workflow questions, adoption questions, and broader product feedback.
- Use [Issues](https://github.com/ychampion/reflective-ai/issues) for bugs,
  install blockers, documentation gaps, and specific feature requests.
- Use the security process in [SECURITY.md](SECURITY.md) for sensitive reports.

## Before Posting

Please remove private information from logs, screenshots, traces, and command
output. Do not post secrets or proprietary code.

## Response Expectations

During the coming-soon period, response times are best effort. High-signal
reports that include environment details, expected behavior, actual behavior,
and sanitized reproduction steps are the easiest to act on.
