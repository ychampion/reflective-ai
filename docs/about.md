# About Reflective

Reflective is a terminal coding harness for AI-assisted engineering.

The product is built around a practical problem: the best coding work depends on
context that usually lives outside the immediate prompt. Engineers rely on
history, conventions, ownership, incidents, deployment constraints, and known
test recipes. Agents should be able to use that context too.

Reflective turns that context into an explicit part of the session.

## Product Thesis

Better agentic coding comes from better operating context, not just longer
prompts.

Reflective is designed to help teams:

- bring relevant memory into a session before work begins;
- capture useful lessons after work finishes;
- encode repeatable workflows as skills;
- run local policy and context hooks at the right time;
- keep verification evidence attached to the result.

## Who It Is For

Reflective is for developers and engineering teams that already use terminal
workflows and want AI agents to behave with more context, discipline, and
continuity.

It is especially relevant for teams with:

- complex repositories;
- repeated operational incidents;
- undocumented conventions;
- fragile deployment paths;
- domain-specific test recipes;
- review standards that agents need to respect.
