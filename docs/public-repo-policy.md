# Public Repository Policy

This repository exists to help developers discover, evaluate, and give feedback
on Reflective.

## In Scope

- product explanation;
- public roadmap;
- changelog and release notes;
- installation docs when available;
- feedback and issue tracking;
- generic skills and hooks;
- public discussions about developer workflows.

## Out Of Scope

- private CLI source code;
- internal architecture notes;
- confidential roadmap details;
- proprietary customer examples;
- private logs, credentials, or company data;
- source-level support requests for code that is not public.

## Maintainer Standard

Public material should be accurate, professional, and grounded in shipped or
clearly marked upcoming behavior. Avoid hype, unsupported claims, and private
implementation detail.
