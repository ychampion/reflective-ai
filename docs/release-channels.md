# Release Channels

Reflective public distribution is not open yet.

When public beta opens, release channels will be documented here.

## Planned Channel Language

- **Private dogfood**: internal and invited usage before public distribution.
- **Public beta**: public installation with known limitations and active
  feedback collection.
- **Stable**: recommended channel for regular team usage once compatibility,
  upgrade, and support expectations are settled.

## Changelog Policy

Public changelogs should describe user-visible behavior, compatibility notes,
known limitations, and upgrade steps. They should not expose private source
history or internal-only implementation details.
