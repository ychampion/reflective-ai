# Install

Reflective public installation is coming soon.

This page will become the canonical install guide when public beta opens.

## Expected Public Flow

The intended CLI command is:

```bash
refl
```

Public beta instructions will include:

- supported operating systems;
- supported shells;
- install and upgrade commands;
- uninstall commands;
- first-run setup;
- provider/auth setup;
- troubleshooting for PATH, terminal, and permission issues.

## Current Status

Reflective is currently invite-only. There is no public install command to run
yet.

Star or watch this repository to be notified when the public beta opens.

## What Not To Do

Use only install commands published in this repository or another official
Reflective channel.
