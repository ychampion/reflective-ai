# Roadmap

This roadmap describes the public direction for Reflective. It is intentionally
product-facing and does not expose private implementation plans.

## Now

- Prepare the public repository for discovery, feedback, and beta readiness.
- Publish clear docs for what Reflective is, what it is not, and how teams can
  evaluate it.
- Collect workflow feedback from developers who use terminal agents today.
- Build a useful public library of generic skills and hooks.

## Next

- Publish public beta installation instructions.
- Document the first supported platforms and shell environments.
- Add first-run onboarding for provider setup, repo context, permissions, and
  local verification.
- Publish example workflows for:
  - incident-aware debugging;
  - regression-test selection;
  - pull request review prep;
  - release note drafting;
  - team convention capture.
- Add public troubleshooting docs for common install, auth, terminal, and
  permission issues.

## Later

- Publish stable release channels and upgrade policy.
- Expand public examples for teams, hooks, skills, and memory review.
- Add public benchmark methodology before making benchmark claims.
- Publish guidance for enterprise evaluation, security review, and rollout.
- Support richer community contributions around reusable workflows.

## Non-Goals For This Repo

- Publishing Reflective's private source code.
- Exposing internal architecture notes that are not intended for public review.
- Accepting examples that contain proprietary company data.
- Making unsupported benchmark or performance claims.
