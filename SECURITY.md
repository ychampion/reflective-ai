# Security

Security reports are taken seriously.

This public repository is not a safe place to disclose secrets, private source
code, customer data, credentials, exploit details, or sensitive logs.

## Reporting

If GitHub private vulnerability reporting is available on this repository, use
that path.

If it is not available, open a minimal public issue titled "Private security
report channel requested" and do not include sensitive details. A maintainer
will follow up with an appropriate private channel.

## What To Include Privately

When a private channel is established, useful reports include:

- affected Reflective version or release channel;
- operating system and shell;
- concise reproduction steps;
- impact and expected behavior;
- sanitized logs or screenshots;
- whether credentials, files, memory, hooks, or tool execution are involved.

## Public Issue Hygiene

Do not paste:

- API keys, tokens, cookies, passwords, SSH keys, or invite links;
- private repository contents;
- customer names or internal project names;
- unredacted stack traces containing paths, usernames, endpoints, or secrets.

## Scope

This file covers the public Reflective repository and public distribution once
available.
