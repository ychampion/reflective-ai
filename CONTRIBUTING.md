# Contributing

Thanks for helping shape Reflective.

This repo is for product feedback, documentation, public examples, changelogs,
and community workflow discussion.

## Good Contributions

Helpful contributions include:

- clear bug reports with sanitized reproduction steps;
- workflow feedback from real terminal-agent usage;
- public skill or hook examples that are generic and reusable;
- documentation fixes;
- installation or onboarding questions;
- adoption blockers from individual developers or teams.

## Before Opening An Issue

Please check:

- existing issues for duplicates;
- the [install status](docs/install.md);
- the [feedback guide](docs/feedback.md).

## Public Safety Rules

Do not include:

- private source code;
- customer or company data;
- secrets, tokens, keys, passwords, invite links, or private endpoints;
- internal stack traces or logs that have not been sanitized;
- confidential implementation details from your company.

If a report requires sensitive details, open a minimal public issue asking for a
private disclosure channel without including the sensitive content.

## Pull Requests

Pull requests are welcome for public docs, templates, and examples.

For examples:

- keep them generic;
- explain the workflow and risk boundary;
- avoid vendor-specific secrets or private infrastructure;
- include enough context that another team can adapt the pattern.

For docs:

- use direct, concrete language;
- avoid hype and unsupported claims;
- prefer current status over aspirational wording;
- mark future functionality as coming soon unless it has shipped publicly.

## Maintainer Review

Maintainers may close issues or PRs that are off-scope, contain sensitive
material, duplicate existing discussions, or request non-public details.
